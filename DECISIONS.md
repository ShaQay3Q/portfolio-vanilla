# Portfolio decisions

## 2026-07-22

### Why vanilla HTML/CSS?

I want to understand the browser before using a framework.

---

### Why one HTML file?

The site is small.
I want to explore browser navigation using anchors and CSS.

---

### Questions

- Can I build tabs using only CSS?
- How would I implement a blog?
- When would JavaScript actually become necessary?

---

## Navigation

I chose CSS :target navigation because:

- I want to understand browser behavior
- The site has limited dynamic content
- I want zero JS initially

Trade-off:

- More difficult to implement dynamic blog features
